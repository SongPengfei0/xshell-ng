# Roadmap

This roadmap tracks likely work after the initial public repository setup.

## Near Term

- Add UI smoke tests for key workflows.
- Add configurable terminal log directory and log rotation.

## Later

- Drag-and-drop upload/download in SFTP.
- Remote file edit and save-back workflow.
- Remote chmod / permission editing.
- Login scripts and trigger rules.
- Split the large renderer state machine into focused modules.
- Add richer SFTP conflict prompts for per-file decisions.

## Non-goals

- Copying commercial SSH client trademarks, icons, branding, or proprietary assets.
- Storing plaintext SSH passwords or passphrases.
- Bypassing SSH host key verification for convenience.
